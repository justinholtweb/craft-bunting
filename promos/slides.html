Scopes

Sites, groups, people,
or a percentage

Every flag is resolved for a site and a user — Craft's, not an Eloquent model.

Per siteOn for one site, off for another, or a rollout in one market only.
User groupsTarget the groups you already have; changes to membership take effect at once.
PeoplePer-user overrides, and admin previews for your own session only.

Flippable on production: definitions deploy with project config; the rollout lives in the database.

Headless

The answer,
not the rules

Front ends read the answer for the requesting user — never the rules.

  • Public flags only, one permission each
  • Never served from a shared cache
{ buntingFlags(site: "fr") { handle active } } → [ { handle: "new-nav", active: true }, { handle: "new-checkout", active: false } ]
